# Ex.No 1 — Lexical Analyzer with Symbol Table

**Aim:** Develop a lexical analyzer using the LEX tool to recognize tokens such as identifiers, constants,
comments, and operators in a C program and to create a symbol table while recognizing identifiers.

## Files
- `symbol_table.c` — C program implementing a symbol table (create, insert, modify, search, display).

## How to run
```bash
gcc symbol_table.c -o symbol_table
./symbol_table
```
> Note: Original program used Turbo C headers (`conio.h`). On Linux/GCC, remove `#include<conio.h>`,
> replace `clrscr()`/`getch()` calls, and change `void main()` to `int main()` for modern compilers.
